Design System Rules & ADR-009 Governance

Always

One form component, three layout shells — state machines cannot drift apart.
ADR-009: Scoped exception strictly bounded to /signin route.
Seamless video blending: --auth-stage radial matches video background precisely.
AAA text contrast on glass card (17.5:1 white-on-navy, 7.4:1 labels).
Real <form>, real autoComplete, Enter submits — password managers work.

Never

Glassmorphism or gradients leaked into dashboard or inspection screens.
Video auto-looping: plays once, holds final lockup frame cleanly.
Video loading on mobile phones: poster only, saving bandwidth and GPU.
A self-serve password reset flow. Branch admin resets credentials.
Full-page spinner overlay. The button carries the loading state.
